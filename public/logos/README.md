# Brand logos

Drop an SVG here named `<slug>.svg` to override the icon for that technology.
The `slug` is the one set in `src/content/site.ts` · e.g. `aws.svg`, `tableau.svg`.

A file placed here takes priority over everything else. It renders at 28×28.

## Currently using a monogram fallback

Simple Icons no longer ships these marks (mostly trademark removals), so they
render as a coloured monogram tile until you add a real SVG:

- `aws.svg`
- `azure.svg`
- `oracle.svg`
- `pinecone.svg`
- `chromadb.svg`
- `powerbi.svg`
- `tableau.svg`

Official sources: each vendor's brand or press kit page. Use the monochrome or
full-colour mark, trimmed to a square viewBox for consistent alignment.
